# 食物特写 · 莓好一刻

这包使用本次实际生成的透明草莓图片，加上原创印章、共享纸张颗粒、聚焦和曲线路径，演示同一素材如何长出不同画面。

preview.html 是 8 秒快速预览；?variant=macro 与 ?variant=contact 可单独研究微距和纸卡排布。examples/strawberry-remix 是 24 秒完整六幕创意实验，使用同一份可编辑代码。换成当前题材的图片、文案和布局即可继续设计；可以只拿一张图或一个方法。

图片由当前会话原生生图工具生成，已检查真实 PNG、透明通道并转换为 WebP；确切模型版本未由工具返回，未宣称是 image2.5。提示词、来源 SHA、转换后 SHA 和像素尺寸见 assets/provenance.json。照片风格图像是 AI 素材，不作为真实商品或事实证据。

代码和 SVG 印章采用包根目录 MIT 许可。生成图片另标记 generated-original，以实际生成来源记录为准，不将它冒充手绘 SVG 或第三方摄影授权。个人项目文件不自动公开。

字幕、人物、旁白音色和语速继续由用户选择。这是无声视觉实验，可另按项目需求加入声音。
