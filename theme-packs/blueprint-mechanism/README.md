# 蓝图构造 · 看懂一条路径

以斜向机构为舞台，让外壳剖开、内部通道显露、两路标记汇合；完整演示从表面到关系的观察过程。

## 运行与改编

直接打开 `preview.html`，自动播放 10 秒无声短例。`?t=3.5&controls=0` 冻结画面；`window.renderAt(seconds)` 可前后任意跳转。无框架、无 API、无网络或安装。减少动态效果系统设置下默认暂停，可手动播放。

- 立体拆解：默认：透视进入与逐步剖开。可把内部通道替换为概念流程，保留示意标注。
- 正面读图：运行 ?variant=flat：落位后使用平面视角，更适合比较两条路径；路径点与说明可独立编辑。

0–2 秒机构透视落位；2.1–4.4 秒外壳剖开；4.4–7.3 秒通道显露与路径汇合；6.7–10 秒保留解读。

`motion.js` 自行组织镜头，`../shared/narrative-motion.js` 只返回时间采样姿态。颜色、视角、路径、遮罩、文字和每幕长度可分别更改。演示构图可整体重写，无固定镜头表。`renderAt` 是可选播放器接口；引擎适配见 shared/engine-bridge.js。

本例为明确标注的虚构视觉示意。科学、调查或产品内容必须使用核验过的来源与真实限制。用户决定旁白、人物、音色和语速。10 秒仅为材料演示；成片镜头长度依真实内容与音频调整。
