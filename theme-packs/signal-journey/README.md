# 信号旅程 · 空间讲解

一份可拆用的原创矢量素材包：同一个想法从左侧进入，在三个不同深度的节点分路探索，沿弯曲通道重新汇合，最后成为新的理解。画面以位置、距离、颜色与聚焦讲清关系，不靠逐字弹出维持运动。

## 运行两种真实变体

- `preview.html?variant=depth-flight`：空间飞行。透视平面、厚度连线、深度缩放、支路聚焦及轻微镜头推进
- `preview.html?variant=route-map`：平面路线图。移除透视，保留路径时序，让三个分支更容易横向比较
- 任一链接追加 `&t=6.3&controls=0` 可冻结；默认变体为 depth-flight
- `window.render(seconds)` / `window.renderAt(seconds)` 可任意顺序跳转；范围 0–12 秒
- `window.themePreview.play()` / `.pause()` 控制预览。尊重减少动态效果设置
- 本地打开即可，无网络、React、构建器、字体下载或第三方运行时依赖

## 材料，而非强制模板

| 文件 | 可拆用内容 |
|---|---|
| `assets/packet-token.svg` | 独立的抽象消息图标，可替换成用户自己的标志 |
| `assets/plane-grid.svg` | 轻量坐标底纹，适合几何场景的空间尺度提示 |
| `assets/route-atlas.svg` | 完整、可编辑的空间关系矢量图，可放进其他 HTML 场景 |
| `assets/poster.svg` | 独立封面，无外部链接或字体资源 |
| `motion.js` | 三维点投影、分支路径、消息沿线移动、节点响应、视角切换 |
| `styles.css` | 深墨绿背景、低亮度玻璃平面、薄线、局部三色强调 |

坐标、连接、颜色与时序集中在 `motion.js` 顶部的 `points`、`links`、`colors`。每条连接为 `[起点, 终点, 颜色索引, 开始秒数, 持续秒数]`。`curve()` 定义弯曲路径，`project()` 定义镜头投影；可单独取走，不要求保持页面结构或固定元素 ID。不要将本示例 12 秒当成实际影片时长约束。

`SignalJourney.points` 与 `.links` 提供读用入口，不要在生产期间原地修改；复制后按内容改写。主播放器是预览壳，生产渲染可载入 `../shared/engine-bridge.js` 接入现有引擎。

## 时间叙事

1. 0–2.5 秒：空间展开，消息从起点抵达分路节点
2. 2.5–5.1 秒：三个颜色对应三条路径，镜头缓慢靠近；非重点平面降低对比
3. 5.1–8 秒：三份探索结果沿不同曲线回到同一汇合点，镜头回到全景
4. 8–10.1 秒：汇合后仅保留一个向前移动的消息，到达终点并变为图标
5. 10.1–12 秒：稳定停留，便于接旁白收束或切下一镜

阶段文字使用温和、正向的中文示例：观察、连接、尝试、汇合。动画不包含人物或配音，也不会改动用户所选的音色、语言、语速或人设。

## 自由改编与信息边界

这是关系隐喻，并不描述真实计算机网络、协议、实际吞吐量、路径长度或同步机制。若用于技术科普，先换成经过核实的节点和连接，再准确标注实际系统边界。颜色只是路径身份，没有定量含义；合流不声称是真实网络包重组。

9:16 版建议把左右起终点转成上下布局，三个支路按三列排列；不建议把整幅横图直接裁切。正文字幕建议放在画面底部独立安全区，示例底部说明不是自动字幕。可降低 `inspect` 镜头量、取消光晕或将全部 z 设为零，获得更安静的讲解。
