# 编辑数据 · 关系的形状

纸白网格上的朱砂折叠雕塑，以全宽中文标题、等轴构型和边注连接抽象概念；不是柱图数据模板。

本包是原创可拆材料，不是镜头语法或必须套用的模板。HTML/CSS/JS 为完整参考代码，SVG 可独立编辑；不用 React、打包器、网络或模型 API。素材及代码采用 `../LICENSE` 的 MIT 许可，可修改、商用和再分发，保留许可声明。

## 打开与取帧

打开 `preview.html` 播放 8 秒无声动画。`preview.html?t=3.5&controls=0` 固定单帧；`render(t)` / `renderAt(t)` 按秒 seek 并暂停，范围 0–8。乱序 seek 每次重算，不累积状态。系统减少动态效果时停在 4.96 秒，可自行点击播放。窄窗等比留边，未暗中裁切为竖版。

## 自由改编

### 证据地形

用经核验的真实数值重建柱高、共同零基线、单位和来源；先删掉本示范概念标签。让一组对照而非装饰浮动解释关键差异。

### 概念折页

将每个折面拆成一张不同的观点卡，横向、环形或对角组合；无数值时明确写“概念示意”，不要暗示增长。

### 一组关系

只保留两个材料和一条连接，让一条经过验证的关系成为整帧；标题可以在底部或穿插其中。

### 拆用方式

折叠 SVG 与地面网格可独立使用。拆用顶面、正面和侧面的层次，可重建新的纸带、时间序列或数据雕塑；不规定五柱或固定标题位置。

### 参考时间

0.1–1.1 秒标题进入；0.35–2.49 秒纸柱错时展开；1.6–3 秒边注出现。后段极轻浮动只是概念雕塑，可删除或由内容节奏替换。

### 竖版适配

保留单列大字标题，把五个材料改为两行或只留两个。边注移到主物体下方；竖版重绘网格，不直接裁切横版。

### 字幕安全区

底部 80 像素为参考页脚带，成片需移走页脚留给字幕。图表单位和字幕不得共用同一基线。

### 边界与误用

五个概念的柱高只是构图，不是重要性、排名或实测数值。真实图表必须有一致比例、零基线、来源、时间范围和单位；关闭装饰性浮动，避免扭曲数值。

## 接入视频项目

复制需要的资源、CSS/JS 及 `../shared/` 并修正相对路径，或只提取需要的几何和时间函数。场景结构、元素类名和八秒时长都不是成片约束；按用户内容和真实旁白组织新的镜头。可选在 player 后加载 `../shared/engine-bridge.js` 适配已有 renderer 的 pause/time/duration 三接口；它不是 GSAP，也不代表本包完成了成片音轨验证。

用户对旁白、人物、音色、语速的选择始终优先，包不会替换这些内容。浏览器像素与离线检查见上级 `tests/`；最终成片仍需检查字幕、音轨、事实来源与真实导出。
