# 第一轮：主题材料与原生生图

## 本轮成果
- 新增 6 个可拆用资源包：精密产品、编辑拼贴、空间科普、纸艺、动态海报、有机光感。包含原创 SVG 素材、共享材质/运动工具、自由改编说明和 8 秒 HTML 动态参考。
- 原有 23 个方向加入 6 秒可播放参考。它们目前属于“风格动效”，新增 6 个属于“素材包”，UI 分别标示成熟度；原创方向仍可选择。
- 选择器悬停/键盘聚焦播放，选中后显示动态参考。预览运行在隔离 iframe；无工作台父页面访问权、无网络请求权限。减少动态偏好提供静止画面。
- 图片创作设置：允许 AI 按需生图或仅用现有素材/代码，附可选图片方向。新 video-image-assets skill 指导当前 Codex 调用原生工具、取得真实图片、检查并加入 HTML 场景。
- 新 app.image_assets CLI：素材计划、实际图片验证、哈希快照和来源记录。不会调用模型 API，不需要密钥，不声称网页能唤醒模型。
- 实际完成一次原生透明棱镜生图，PNG 检查后转换为保留透明通道的 WebP，运行素材记录与预览注册，并提供 examples/image-material-study 离线 HTML 演示。工具未返回确切模型名，未伪称 image2.5 验证。

## 继续迭代的重点
1. 用不同题材验证每包的迁移能力，并持续扩展有明显差异的主题；按需要补齐旧 23 主题的真正素材。
2. 建立更方便的资源查找/复制命令，展示共享资产与示例，降低普通模型理解成本。
3. 强化手机端独立动画预览、播放/暂停操作及自定义主题的动画资源导入；旧自定义主题的静态参考仍兼容。
4. 将已讨论的需求页分组方案落实，保持一次需求确认和既有三种模式。
5. 继续做实际 HTML 成片和生成素材组合测试，优先改进视觉叙事，而不以主题数量作为唯一进度。

## 边界
底层继续 HTML/CSS/JavaScript；本轮未加入 React/Remotion。用户选择人物、旁白、音色和语速。所有新增素材包为原创示例，保留参考网站及许可记录。没有外部付费 API、没有读取个人密钥。

Linux 浏览器测试不等于 Windows 全平台验证。图片记录的生成来源由作者声明，文件校验不构成模型来源证明。

## 核验结果
- Python：154 项通过（含跨进程取消、缺少解码器拒绝登记、精确字节快照、替代 URL 沙箱回归）
- 浏览器：既有 UI/音色/凭据安全/BGM/新项目/项目隔离/完整创作流程，加主题动态与图片设置、延迟刷新竞争检查均通过
- 6 包：离线加载、时刻复现、边界 seek、播放控件、减少动态、390px 视口和适配器测试通过；逐张检查渲染帧
