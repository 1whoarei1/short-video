# 第六轮：光学质感、电影式景深与中文兼容

## 两个可拆用的新材料包
- prismatic-lab：复用此前实际生成的透明棱镜图片，保留原始来源与文件哈希。黑色光学台和温暖珍珠背景两种版本，包含微距揭示、镜头拉开、移动光线、彩色光斑、倒影与细节标注。为分层二维表现，不声称是真实三维光学模拟。主文案已换成简短中文，实际渲染帧作为封面。
- cinematic-landscape：六层原创程序化山谷、岩面纹理、溪流、薄雾、浮尘与近处松枝视差，提供晨光和月夜两种版本。种子与时间决定每帧，允许跳到任意时间重现。虚构地貌，附三份独立可编辑 SVG，可拆出地形、前景与光照方法。

两个包均为 12 秒无声预览，复用共享播放器和运动接口。现在总计 15 个材料包 + 23 个旧主题动态参考，继续保留原创方向。用户选定旁白、人物、音色与语速不受这些材料影响。

## 新机器审查与修复
- 独立审查发现 Windows 非 UTF-8 默认编码可能让中文资源目录、素材计划和登记记录读取失败。服务端目录接口和两个资源模块已显式读写 UTF-8，加入模拟 cp936 默认编码的三个回归
- 资源目录加载失败时工作台现在有明确提示，项目仍可编辑，恢复后刷新即可；不再悄悄丢掉材料包
- 主题测试改用仓库锁定的 playwright-core，避免依赖当前电脑恰好装有全局 playwright
- 所有已登记包均纳入实际 copy 回归；复制来源描述改为中性词，旧清单保持原字节且仍可幂等复用
- 第三方声明已纠正：旧主题确实附带 OFL 字体子集与对应许可。材料库说明更新至当前目录，区分原创代码/SVG 与 AI 图片的来源记录

## 验证
- 203 项 Python 测试、20 组浏览器/渲染回归通过
- 15 包共同预览检查通过，新包各两个变体另做确定帧、乱序取帧、冻结、减少动态、手机控件及引擎桥接检查
- 新包经实际资源 copy 到独立项目，再通过原有引擎导出合计 24 秒、576 帧、1280×720、24fps、H.264 无声样片；全片解码通过
- 两种新风格的主要代表帧已查看，中文排字无裁切，主体与光线不压住标题
- 仍仅实测 Linux/Chromium，Windows 编码与路径属于模拟回归；尚未做原生 Windows 验收或 Luna 质量对照实验
