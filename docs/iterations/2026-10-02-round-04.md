# 第四轮：真实图片素材与个人主题动画

## 一个新题材的完整练习
新增 food-editorial 食物特写包。实际调用当前会话原生生图工具制作了透明背景草莓，保留原始提示词、尺寸、来源与 SHA-256；转为保留透明度的 WebP，并放入真实 HTML 场景。工具未返回底层模型版本，因此不声称验证了 image2.5。

8 秒主题预览可以播放、暂停、拖动和定点取帧。完整 examples/strawberry-remix 是 24 秒、六幕的新题材练习：主角进入、微距放大、照片拼贴、文字与物件交叠、曲线路径、收尾。它借用了共享纸张、聚焦与路径资源，并重新设计了构图。另有微距和拼贴两个可运行变体。

这是实际素材组合和渲染的验证；尚未进行 GPT-6-Luna 使用前后的质量对照实验。现在共 12 个资源包、23 个风格动效方向，另保留原创方向。

## 自定义动态主题
个人主题支持可选短 MP4/WebM：项目上传或既有产物 → 创建主题时选择 → 放大原生播放 → JSON 导出/导入。图片主题保持兼容。主题查看和使用分开，旁白、人物、音色与语速仍由用户选择。

实际校验容器、浏览器兼容编码、尺寸、时长及完整解码；使用不可变字节快照。创建、导出、导入共用 7 MB 图片与视频合计上限，防止导出后不能导入。具体限制和使用方式见 docs/custom-theme-animation.md。

独立审查发现并修复了合计大小不一致和浏览器不支持的视频编码问题，也补齐了探测阶段的资源限制。审查回归全部通过。
