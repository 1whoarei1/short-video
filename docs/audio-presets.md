# 统一音频试听与组合预设

在需求页打开“声音与音乐”，可在同一面板选择渠道、音色、最终语速、音乐来源、两路音量与说话时的避让。原来的自由原创、上传音乐、无配音和无音乐仍可单独选择。

“只听配音”“只听音乐”“一起听”使用同一播放控制；暂停保留位置，停止归零。重复点击正在播放的模式会暂停。切换声音、音乐、关闭面板或返回其他页面会停止旧音频，避免叠播。

试听全部来自本地文件，不调用 TTS 或音乐生成服务。语速滑块将预录配音以 0.5–2 倍播放，在浏览器支持时保持音调；同一百分比保存为最终 Azure/Edge 的 TTS rate。实际合成会根据文字形成自己的节奏和停顿，因此本地变速只是参考。没有预录样本的自定义音色仍可选择，但不能假装已听到该音色。云帆样本是已有的真实 Azure 录音；部分其他 Azure 音色使用明确标注的同名 Edge 参考。

五条内置 BGM 为此次原创的轻快科普、克制悬疑、科技、温暖与纪录叙事循环。WAV、编曲代码、CC0 许可、精确长度和来源哈希均随仓库分发，克隆后即可试听。每段约16–18秒，是完整八小节的短循环。选择“内置原创循环”用于成片时，引擎重复同一音源至实际视频长度，并做首尾安全淡入淡出；它不是另行创作的完整长曲。需要随镜头变化的长曲时仍选择自由原创。

配音音量为 −24 至 +6 dB，音乐为 −60 至 +6 dB 的额外增益。有配音时，音乐先降低12 dB，再按所选轻柔／标准／明显策略动态压低。音乐单播以无配音基准播放。浏览器检测真实配音录音的 RMS，包含配音增益，以共享的阈值、比例与攻放时间控制音乐；最终 FFmpeg 使用相同参数。浏览器平滑和 FFmpeg 检测器实现、实际配音的声级与停顿存在差别，最终仍以真实混音检查为准。

“保存组合”只保存当前音频选择，不改变已批准的项目；明确“应用”才更新需求并按原规则使下游需要重新核对。内置组合可选，不是默认强制主题。新项目默认仍无配音／无音乐，也可在创建时明确选择内置或当前项目已保存的组合。用户组合保存在当前项目，切换项目不会自动套用。上传音乐组合只用于原项目，不向其他项目复制私人源文件。预设没有密钥字段；Azure 凭据继续由用户通过专用安全设置配置。

## 制作与缓存

内置循环在真实语音或无声时间轴确定之后准备：

```powershell
python scripts/engine.py configure PROJECT
# 首次配音才执行 synthesize；只改音量无需重新TTS
python scripts/engine.py timeline PROJECT
python scripts/engine.py bgm-prepare PROJECT
python scripts/engine.py soundtrack PROJECT
python scripts/engine.py render PROJECT
```

人声音量变化只需重新混音；不改变已有配音缓存或词边界。语速或音色变化需要重新合成。循环音源、目录、时间轴、混音策略和各项增益都进入新鲜度／哈希核验。更新到本版本后，旧混音记录会保守地需要重建；已有声音选择保持不变。无声模式继续排除旧配音，缺配音或过期音乐不会静默导出。

共享参数位于 `web/presets/audio-mix.json`，循环目录位于 `web/presets/bgm/catalog.json`。`tests/audio-presets-browser.cjs` 实测实际播放、AudioContext、增益、动态避让、保存／恢复与页面返回；Python 的 audio-presets、soundtrack-presets 和 audio-preset-renderer 测试覆盖实际 PCM／编码视频及缓存失效。
