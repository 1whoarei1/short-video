# 背景音乐工作台

背景音乐与配音独立选择。旧项目和新项目都默认不加背景音乐；“无配音 · 字幕”只表示不生成旁白，仍可配音乐。

## 需求页

- **不使用背景音乐**：保持原有字幕 / 配音流程。
- **内置原创循环**：五首本地原创短样，在“声音与音乐”单独或同时试听、调独立音量和避让、保存组合；明确选用后重复到实际时间轴长度，不冒充新创作的长曲。详见 [音频预设](audio-presets.md)。
- **AI 原创 · 真实采样音色**：可填写自由的音乐方向，也可留空。Codex 随主题、叙事与画面自由作曲，用 MIDI 和真实采样音色完成演奏；不套固定曲式、乐器组合或某个示例旋律。文字方向是参考，不是机械约束。
- **使用我的音乐**：选择有权使用的本地音频后点击“导入音乐”。支持 WAV、MP3、M4A、OGG、FLAC，单文件最大 32 MiB、时长最多 60 分钟。服务端检查真实音频，拒绝仅改后缀的非音频、视频和无效文件。需要本机 FFmpeg / ffprobe。源文件保存到本项目独立快照，原文件不会被修改。文件过大时请先让 Codex 制作适合视频的片段，不要绕过上传检查。

选择、方向文字和音乐来源随需求草稿保存。保存不会调用模型、合成配音或立即生成音乐。音乐来源切回“不使用”时不会删除已导入源文件，之后可重新选择使用。

## 五阶段内完成

1. 需求沟通：选择配音和背景音乐，确认需求。
2. 文案（含调研）：先确定内容和讲述节奏。
3. 静态预览（手动/半自动）：画面预览旁放音乐短样。播放器支持播放、暂停、拖动进度；在本阶段的审核备注中给出音乐修改意见。短样与画面共用原有确认点，不新增强制审核阶段。
4. 视频制作：Codex 完成整曲、匹配视频实际长度、混音并核验。原始音乐源文件保留不变，工作用整曲按实测响度以单一固定增益向 -18 LUFS 调整，真峰值不超过 -1.5 dBTP；高动态曲目优先保留动态与峰值，不强加压缩。只有音乐时默认保持工作整曲音量；有旁白时默认额外压低 12 dB 并自动避让人声。bgm_gain_db 默认 0，表示在此基础上的额外调整；片尾自然淡出。配音试听和语速设置只作用于配音，不给音乐变速。
5. 导出：检查最终视频内实际可听见的音乐、人声与结束点，不能只检查独立音乐文件。

音乐在人声期间隐约可闻、停顿时适度恢复，按本项目及用户听感调整，不固定照抄前片增益。信号检查记录实际混音电平、峰值、同步与结束点；听审另记，没听过就不声称听过。只调整音乐或增益时保留已批准的文稿、原配音与画面，重建混音和绑定验证。参见 [成片验收](creative-method.md)。

全流程模式逐步由人确认；半自动模式在静态预览一起确认画面和音乐方向；全自动模式跳过静态预览与短样审核，直接创作整曲、制作视频并核对最终音轨后导出。实际混音与视频绑定校验仍然必需。
