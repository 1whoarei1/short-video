# 仓库内容与本地产物

仓库保存运行代码、工作流技能、当前使用说明、15个主题素材包、23个动态主题、五条BGM、音色试听、独立可运行示例，以及第三方许可和来源记录。这些离线资源用于新环境预览与创作，不能只留下截图说明或不可复现的下载链接。

用户项目默认在被忽略的`workspace/`。项目历史、不可变快照、渲染帧与检查点、配音缓存、最终混音、发布交付包和本机配置也留在本地。`.gitignore`不保护已跟踪文件，提交前仍需检查文件范围；自建项目建议放在默认workspace或仓库之外。Git迁移源码，用户自行备份整个workspace；凭据在新电脑由用户重新配置。

2026-10-06整理删除17个已跟踪文件，Git历史完整保留：

- 12份过期迭代、恢复与交付记录共33,111字节；其中临时目录、待推送状态和旧提交结论已不适用，首次使用统一看[新机器设置](new-machine-setup.md)。
- 通用发布演示的ZIP、导出文案、清单和运行报告共227,350字节；与独立源码、文案输入及预览图重复，改由[构建脚本](../examples/publishing-package-demo/README.md)在独立输出目录实际重建。
