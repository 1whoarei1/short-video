# 本次迭代怎么验收

## 先看成果

建议先看《山间来信》28 秒短片，再看《草莓素材重组》24 秒短片：前者把多个包的部件改写成一支有持续主体的新片，后者实际使用了原生生图得到的透明图片。材料总览展示 15 个包的完整短动画，可用来挑选后续视觉方向。

这些样片都是无声视觉验证，音频配置仍沿用你在工作台选择的方式。另有棱镜与山谷 24 秒组合演示。样片、代表帧和回归证据在交付压缩包的 proof/ 中，完整源码在 short-video/ 中。

## 项目现在有什么

- 15 个 HTML/CSS/JS 材料包：本地图片或 SVG、参考代码、共享质感与运动、短动画、改编说明和来源记录
- 原有 23 个风格方向均有短动画参考，保留原创方向；材料可以跨主题使用和自由改写
- 主题支持放大播放、暂停与拖动；个人主题可携带短 MP4/WebM 导出/导入
- 需求页分成三个可任选的分组，依然一次确认；320px 小屏、长名称、媒体预览与批注控件做过实际检查
- 生图流程使用当前 Codex 真正具备的工具，图片实际保存、解码、登记并用于场景；没有项目模型 API 配置
- 环境检查区分 UI、渲染、图片与可选声音；中文资源用 UTF-8，渲染缺图或错误时长会明确报错

## 在自己的 Codex 中尝试

1. 先用交付包中的完整源码打开新项目目录。当前夜间修改还保存在本地，GitHub 公共仓库尚未同步；直接拉远端会得到之前的版本。
2. 新对话里说「我要制作视频了」。按 [新机器说明](new-machine-setup.md) 检查并启动工作台，创建一支空白新视频。
3. 填主题、受众和约略时长，提交自己的材料，选择模式。人物、旁白、音色和语速由你设置。
4. 看几种动态参考后选择方向，也可以填写原创要求。AI 按 [自由改编指南](visual-remix-guide.md) 挑少量资源、按内容创作；静态预览展示真正素材进入 HTML 后的效果。
5. 用截图、时间位置和框选意见要求修改，再按选择的模式完成后续阶段。

界面不会唤醒已经关闭或空闲的 Codex 对话。正在等待时保持当前任务；超时后回到对话说「继续当前视频项目」。你无需把模型密钥交给这个项目。

## 实测范围

自动回归检查了保存、模式、媒体、声音选项保留、目录、图片登记、复制、确定性取帧与导出。干净源码能够启动 UI、创建新项目、加载素材并导出实际视频；本地 Git 增量恢复也已核验。

这些结果证明功能和文件流程可用。还需要你在自己的新 Codex 对话中进行一次真实创作验收：我们没有以工具测试代替这个模型行为，也没有做 GPT-6-Luna 的审美质量对照。图像工具未返回精确底层型号，不能据此宣称 image2.5 已验证。Windows/macOS 原生仍未实测，详见 [干净检出验证](clean-checkout-verification.md) 和 [最终恢复记录](final-recovery.md)。

## 版本与资料保护

素材来源、第三方字体许可和生成记录留在仓库对应目录。个人 workspace、凭据、缓存与 node_modules 不放入源码交付。当前仓库是 public；确认同步范围后再发布本地提交，不改变仓库可见性。

交付 Git bundle 是增量包，需先有基础提交 e6d0504014fd223db060351e7177eccfb71d1da3。恢复前运行 `git bundle list-heads` 查看实际导出分支，按该引用取回。也可直接使用完整源码而不恢复 Git 历史。
