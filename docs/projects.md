# 开始新视频与切换项目

点击工作台左上方的 **“＋ 开始新视频”**，填写名称，再点击 **“创建并开始”**。

新视频从空白需求开始，使用默认的全流程确认模式，不复制旧项目的素材、文案、配音、音乐或制作进度。旧视频和已保存的历史会完整保留。关闭新视频窗口、按 Escape 或浏览器后退不会创建项目；还没提交的名称可以保留后再次打开填写。

在“当前项目”下拉框中切换回来即可继续旧视频。页面有未保存修改时，会先询问是否放弃；取消即可回到原草稿。建议先保存需要保留的编辑，再切换或新建。

工作台记住最后选择的项目，下次打开服务首页会回到它。已打开的其他标签页仍固定到各自项目，不会因为另一个标签页切换项目而改写错误的视频。

## 与 Codex 协作

每个项目有独立工作目录。工作台“复制继续指令”会包含当前项目的完整目录和明确的 `--workspace` 参数。把这条指令发给当前 Codex，让它读取对应项目状态后继续。

在仓库根目录执行 CLI 而省略 `--workspace` 时，会使用工作台最后选择的项目；给出明确路径时始终使用该路径。不要将旧项目的路径继续用于新视频。网页只记录和显示任务，不会唤醒已结束的 Codex 对话。

新视频工作目录位于启动工作台时指定 workspace 的 `.studio/projects/` 中。备份整个 workspace 可同时保留原视频、项目索引与新视频，不要只复制某个成片。
