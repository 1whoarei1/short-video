# 需求页分组

需求沟通仍然是一个阶段、一次确认。页面用三个可任意切换的分组降低拥挤：

- 内容与资料：项目名称、想讲什么、自己的参考材料
- 画面与声音：主题素材包、图片创作方向、旁白音色、语速与背景音乐
- 交付偏好：画幅、约略时长或时间区间、审核模式和更多输出设置

切换分组保留未保存的输入，不保存、不提交、不启动 AI。右侧概览立即反映选择，点击对应条目可跳回设置。全部准备好后，使用原来的“确认需求并开始”。用户可以直接使用默认值，无需逐个访问分组。

手动/半自动/全自动和五个阶段保持原语义。人物、音色及语速由用户选择；选择主题和借用素材不改动这些设置。

实现位于 web/brief-workspace.js，复用原有字段与保存协议。测试中的 brief-ui-helpers.cjs 通过真实分组按钮定位字段，不强行操作隐藏控件。
