# 新题材重组实测：草莓的一刻

24 秒六幕，无声。打开 index.html 可离线播放；也可运行 `python scripts/engine.py render examples/strawberry-remix` 通过现有渲染器导出（先完成环境检查）。

实际做法：
1. 原生生图工具生成一颗透明草莓，保留真实文件和来源
2. 用图片表现质感，用代码安排构图、文字和运动
3. 借用 shared 的纸张颗粒、时间插值和聚焦/曲线路径
4. 自由组合主体特写、镜头放大、纸卡重排、动态排字、散开再汇合和收尾
5. 看实际帧，调整裁切、文字位置和过渡，再导出完整视频

这是从其他主题材料迁移到新题材的可运行示例，证明当前工程能够组合这些能力。尚未做 GPT-6-Luna 的对照实验，不能据此声称已测得它的质量提升。生成图片的确切模型未返回；素材是 AI 图像，不是实拍。

本例没有人物或旁白，后续创作仍保留用户对这些内容的选择。真实素材路径和运动代码在 theme-packs/food-editorial。
