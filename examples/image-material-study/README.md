# 原生生图 → 素材 → HTML

这是一次实际生图验证，不是占位图：当前会话原生图片工具生成透明玻璃棱镜，获得真实 PNG，检查像素与透明通道，转换为保留 alpha 的 WebP，再由 HTML 编排浮动、旋转和构图。

打开 index.html 可离线播放。所有动画来自代码，图片本身是 AI 生成的静态素材。工具没有返回确切模型名，因此 provenance.json 不声称是某个具体版本。在项目里使用哪个生图模型取决于当前 Codex 可用能力。

对应工作流已实际运行 app.image_assets record 和 app.cli artifact。来源声明与文件校验分别记录，不把文件存在等同于真实性或模型来源证明。此物件是概念艺术，不用于证明真实光学规律。
