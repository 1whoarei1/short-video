Azure 本机凭据

仅在执行合成的本机配置，同一 Windows 用户的所有项目共用。Windows 凭据管理器负责加密保护，不写入项目或 Git。macOS / Linux 暂不支持页面保存。

密钥不会回显，也不会写入普通 API、日志或项目历史。具有同一系统账号任意代码执行权限的程序（包括 AI 工具）仍可能读取它，无法保证对这类程序绝对保密。请自己输入，不要在 AI 操作浏览器或录屏时输入。

    网页写入任务文件。Codex 在同一项目中读取需求、调研、写文案并制作；网页不会直接调用模型。
