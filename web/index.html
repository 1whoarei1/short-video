和 Codex 一起制作

在这个项目目录打开新的 Codex 对话，说「我要制作视频了」。Codex 会检查环境、启动工作台，再和你确定这次视频的目标。

  1. 在需求页写主题、受众、时长与参考
  2. 让 Codex 调研并写稿，检查来源与事实边界
  3. 确认稿件后，查看真实场景截图并框选反馈
  4. 确认静态方向后，制作字幕、动画与视频
  5. 检查节奏、字幕与画面，确认并导出
