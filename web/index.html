和 Codex 一起制作

  1. 写需求，放入自己的参考

    主题、受众、想讲清楚的问题，时长只需给个大概。

  2. 选择你想参与的程度

    全流程逐步确认；半自动在静态预览停下；全自动持续到成片。

  3. 确认需求，交给当前 Codex

    网页写入任务文件。Codex 在同一项目中读取需求、调研、写文案并制作；网页不会直接调用模型。

  4. 在这里看真实结果、留下意见

    图片点开看，视频直接播放。前面内容变了，后续会标记需要更新。

如果任务显示等待 Codex，请回到该项目的 Codex 对话说“继续当前视频项目”。已结束的对话不会被网页自动唤醒。
